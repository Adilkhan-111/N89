# CLAUDE.md

Этот файл задаёт контекст для Claude Code при работе в репозитории **N89** — 2D top-down шутера в стиле киберпанк для геймджема.

## Проект в двух словах

- **Название (рабочее):** N89
- **Жанр:** top-down shooter, 2D action, cyberpunk, indie
- **Хук:** динамичный плейстайл в духе Hotline Miami + атмосфера Cyberpunk 2077 / Cyberpunk: Edgerunners.
- **Главная особенность:** необычная стилистика в быстром, жёстком геймплее.
- **Цель:** сделать стильную игру с помощью нейросетей за геймджем.
- **Дедлайн:** 3 дня. Главный риск — не успеть, поэтому **MVP важнее всего остального**.
- **Команда:** Адильхан (прототип механик и основной разработчик), Айбек;, арт, звук, сюжет, тесты — оба.

## Техстек

- **Unity 6000.6.6f1**, шаблон 2D URP (`Assets/Settings/Renderer2D.asset`, `UniversalRP.asset`).
- **Платформа:** PC (клавиатура + мышь).
- **Ввод:** новый Input System (`com.unity.inputsystem`), ассет `Assets/Settings/InputSystem_Actions.inputactions`. Старый `UnityEngine.Input` не использовать.
- Подключены: 2D Animation, Aseprite/PSD importer, Tilemap (+ Extras), SpriteShape, Timeline, uGUI, Test Framework.
- Язык кода — **C#**. Visual Scripting установлен, но не используется.
- Доступен Unity MCP (`mcp__unity-mcp__*`): можно читать логи консоли, делать скриншоты сцены и выполнять команды в редакторе.
- Папка `Assets/Welcome/` — служебная часть шаблона, игровой код туда не класть.
- Шрифты — `Assets/_Project/Art/Fonts/` (Monoton, Audiowide — OFL; Permanent Marker — Apache 2.0; лицензии лежат рядом). Кириллицы в них нет, поэтому тексты UI пока на английском.
- Главное меню (`Assets/_Project/Scenes/MainMenu.unity`) пересобирается через меню редактора **N89 > Build Main Menu Scene** (`Scripts/Editor/MainMenuSceneBuilder.cs`). Пересборка затирает ручные правки сцены.
- Туториал (`Assets/_Project/Scenes/Tutorial.unity`) — **N89 > Build Tutorial Scene** (`Scripts/Editor/TutorialSceneBuilder.cs`). Пересоздаёт сцену, префабы в `Prefabs/` и временные спрайты в `Art/Sprites/Generated/` (рисуются кодом в `SpriteFactory.cs`; настоящий арт — заменить PNG с теми же именами). Данные взломов (`ScriptableObjects/Quickhacks/`) создаются один раз и дальше тюнятся в инспекторе.
- Реплики голоса и шаги туториала — в `Scripts/Tutorial/TutorialDirector.cs`. Туториал из двух частей: калибровка в шестиугольной лаборатории → побег (89 взламывает шлюз, бежит через охрану корпорации Е, у выхода его убивают в спину, камера улетает вверх, итоговый экран с рейтингом «не оценено» и кнопкой «Вперёд»).
- Интерлюдия перед миссией 1 (`Assets/_Project/Scenes/Interlude01.unity`) — **N89 > Build Interlude 01 Scene** (`Scripts/Editor/Interlude01SceneBuilder.cs`). Квартира главного героя в стиле Cyberpunk 2077 (металл, неон, голоэкраны): он спит на диване, просыпается, дальше игрок ходит по квартире. В комнате справа сверху — арсенал и терминал. Цели — в панели «ЗАДАЧА» слева сверху: «Зайди в ванную» → брифинг → «Иди в арсенал» → у витрины открывается экран выбора снаряжения (см. «Арсенал» ниже) → «Иди к двери» (входная дверь `Door` открывается при подходе) → «Выйди из коридора» (коридор мегаблока за дверью) → экран загрузки миссии 1 (`Scripts/UI/LoadingScreen.cs`). Когда герой заходит в ванную, босс присылает брифинг в мессенджер (`Scripts/UI/MessengerPanel.cs`, стиль журнала сообщений Cyberpunk 2077: панель слева на 60% экрана, сообщения печатаются, в конце файл с координатами; герой не отвечает, Enter, Space или ЛКМ закрывает). Тексты брифинга — поля `InterludeDirector`. Интерлюдия после брифинга не заканчивается — продолжение будет описано. Сценарий — `Scripts/Interlude/InterludeDirector.cs`. После туториала кнопка «Вперёд» ведёт сюда.
- Интерлюдия перед миссией 2 (`Assets/_Project/Scenes/Interlude02.unity`) — **N89 > Build Interlude 02 Scene** (`Scripts/Editor/Interlude02SceneBuilder.cs`). Та же квартира и механики: сборщик зовёт `Interlude01SceneBuilder.BuildApartment` и донастраивает режиссёра поверх (`SaveScene` сохраняет под своим именем). Начало — `InterludeDirector._opening = WatchTv`: Рэй сидит на диване лицом к телевизору (`_sitPoint`), камера с `TvCamPoint` медленно наезжает на него, приходит брифинг прямо на диване (камера — `MessageCamPoint`, Рэй справа от панели), после него Рэй встаёт → «Иди в арсенал» (арсенал миссии 2) → дверь → коридор → загрузка `Mission02`. Брифинг: компромат на «Арка Системс» (дочка второго монополиста синей крови), здание посреди города, на вид обычный офис, но с сильной защитой; файл `АРКА_СИСТЕМС.loc`. В ленту мессенджера влезает ~4 сообщения средней длины — прокрутки нет. Кнопка итогового экрана миссии 1 ведёт сюда. В конце миссии 2 — подвал с Боссом, который оказывается другом Рэя из прошлой жизни и называет его настоящим именем — Брайс (см. «Миссия 2»). Задумано на будущее: в прологе к миссии 3 Рэй смотрит на себя в зеркало и через 3 секунды отходит.
- Главный герой — **не 89**: у него свой префаб `Hero` (дома без оружия, но целится за мышью) и временные спрайты `hero`, `hero_sleeping`, `hero_sitting` (`SpriteFactory.Apartment.cs`), их заменят на настоящий арт. Анимация ходьбы как в Hotline Miami (у героя и у 89): ноги — отдельный спрайт `Legs` под корпусом (`Scripts/Player/LegsAnimator.cs`, кадры `hero_legs_*` / `player_legs_*`, собираются через `TutorialSceneBuilder.AddLegs`), смотрят по направлению ходьбы, корпус — за мышью; темп шага — `_distancePerFrame` (юнитов пути на кадр: герой 0.5, 89 — 0.6); в катсценах и после смерти (физика выключена) ноги прячутся.
- Миссия 1 (`Assets/_Project/Scenes/Mission01.unity`) — **N89 > Build Mission 01 Scene** (`Scripts/Editor/Mission01SceneBuilder.cs`). Логово банды по схеме от команды. Интерьер 1 этажа (`BuildInterior`, временные спрайты в `SpriteFactory.Mission.cs`): лестница, раздевалка со шкафчиками, Chill room (ковролин, диван, аркадный автомат), Discussion room (паркет, длинный стол, проектор с лучом на экран на стене), качалка (резиновый пол, две скамьи со штангами). Грязь логова (`BuildClutter`, спрайты в `SpriteFactory.Base.cs`): мусор, бутылки, коробки из-под пиццы, окурки, пятна, неоновые теги банды на полу, матрас, бочка с огнём — декор без коллайдеров (кроме бочки), чтобы не мешать патрулям. Двор — закрытая база (`BuildYard`, двор расширен до -10..56 x -10..37 схемы): сетка с колючкой, мешки с песком у E1 и E2, контейнер, генератор, бочки с огнём, прожекторы по углам, таблички, мусор. За забором — крыши мегаблоков с вентблоками и неоновыми вывесками (`BuildCity`, чистый фон). Автоматические раздвижные двери во всех проёмах между комнатами обоих этажей (`Scripts/World/AutoDoor.cs`, `AutoDoorAt`): открываются, когда рядом герой или враг, и закрываются через 0.5 с; закрытая дверь на слое `Door` закрывает обзор врагам и камерам и ловит пули, но NavGrid её не видит. Высокие предметы — слой Wall (закрывают обзор), низкие — Glass (не пройти и пули не пробивают, но поверх видно). Координаты в сборщике — в юнитах схемы (1 юнит = 24 px, здание 46 x 27, левый нижний угол (0, 0)), в мир переводятся множителем `S` = 0.6 (здание 27.6 x 16.2 — тесно, как в Hotline Miami; персонажи и стены не масштабируются, при смене `S` проверить проходы); вокруг двор, вход E1 снизу слева (там старт), E2 справа в коридоре. 17 бандитов (`Bandit`, спрайт `bandit`): закорючки на схеме — стоят на посту, пунктирные петли — патрулируют по кругу (`TutorialSceneBuilder.SpawnPerimeter`). Чёрные точки на схеме — камеры наблюдения (`Scripts/Enemies/SecurityCamera.cs`, 5 штук, `BuildCameras`): водят взглядом влево-вправо, конус обзора на полу обрезается стенами; заметила героя — конус из зелёного становится красным, камера следит за ним, и враги в радиусе `SecurityCamera._alarmRadius` = 10 юнитов от героя (чуть больше слуха на выстрел — 8) идут к нему (`EnemyAI.Provoke`; тревога повторяется раз в 0.5 с, пока камера видит героя, — подошедшие в радиус тоже придут; 0 — звать всех). Взлом «Отключить камеру» (`QuickhackEffect.Disable`, ассет `Quickhacks/CameraOff`, 4 RAM) гасит её насовсем. Сценарий — `Scripts/Missions/MissionDirector.cs`: оружие и спрайт героя (`WeaponData.HeroSprite`, `hero_smg|rifle|shotgun`) из `Loadout`, цели по шагам: «Зачисти первый этаж N/17» → «Поднимись на второй этаж» (вспышка, крупный баннер «ЭТАЖ ЗАЧИЩЕН» по центру — `Scripts/UI/Banner.cs`, стрелка у героя к лестнице и прыгающий маркер над ней — `Scripts/UI/WaypointArrow.cs`, свет на лестнице; зона `_stairsZone`) → затемнение и герой у лестницы второго этажа (с этого момента смерть отматывает ко второму этажу — чекпоинт `mission01_floor2`, Esc и итоговый экран его сбрасывают; охрана наверху оживает через `_floor2Grace` = 1.5 с после появления) → «Убей всех, кроме цели N/14» → «Зайди в кабинет цели» (тот же баннер и стрелка к двери кабинета, зона `_officeZone`) → катсцена: главарь встаёт с кресла и просит пощады, Рэй молча стреляет, главарь падает лицом на стол, синяя кровь растекается (`MissionDirector.TargetCutscene`) → экран «МИССИЯ 1 ВЫПОЛНЕНА». Второй этаж (`BuildFloor2`, схема «2 floor») — та же коробка 46 x 27, сдвинутая в мире на `Floor2Origin` = (60, 0), чтобы этажи не видели друг друга: лестница, длинный зал с ящиками, гостиная (ковёр, столик, два дивана, барная стойка), коридор с 2 камерами, кабинет главаря (стол, кресло, шкафы). Охрана второго этажа — 14 бандитов (`SpawnFloor2Bandits`): 5 в зале, 3 в гостиной, 2 в коридоре, 4 телохранителя в кабинете, из них 3 патруля; в лестничной клетке никого нет. Главарь (`Target`, спрайты `target_sitting|standing|dead`) — не враг: коллайдер на слое Glass, пулей не убивается. Камеры поднимают по тревоге только врагов своего этажа (`SecurityCamera._enemiesRoot`). Смерть — фраза героя и перезапуск уровня; R после смерти перезапускает сразу, и после смерти уровень стартует без заставки и баннера (`MissionDirector.s_restarted`); в туториале R так же перезапускает побег с чекпоинта (кнопка итогового экрана ведёт в `Interlude02`, пока его нет — в меню).

  - **Подвал** (`Scripts/Editor/Mission02Basement.cs`, схема «подвал»: своя сетка 1 юнит = 20 px, мир — тот же `S` = 0.6; коробка 56.15 x 31.3 стоит в мире на `Origin` = (0, -90), подальше от первого этажа). Свет в боковых комнатах слабый и с малым радиусом — зал не просвечивает. Спрайты — `SpriteFactory.Boss.cs`.
  - **Темнота и катсцена** (`BossFight`): в подвале глобальный свет гаснет до `_darkIntensity` = 0.03, лампы зала выключены — через стекло ничего не видно. Герой заходит в зал (`_arenaEntry` за дверью) — летербокс, камера отъезжает на зал, три лампы по очереди мигают и загораются с ударом, Босс в свете бросает реплику — бой.   - **Босс** (`Scripts/Enemies/BossAI.cs`, спрайты `boss|boss_down|boss_dead` — огромный, лысый, в татуировках, кибер-глаз, правая рука — пулемёт, левая — ракетница, ранец с лентой; спрайт ×1.25, коллайдер 0.7). Здоровье 400: пуля снимает 1, клинок «Рук-лезвий» — 8 (`BladeArms._bossDamage`, пополам не разрубить), обрушение потолка — 100 (1/4), газовый баллон — 50 (1/8). Атаки по кругу: пулемёт (раскрутка `_spinUp` = 0.8 с, стволы светятся → очередь `_burst` = 2.4 с, ведёт за героем со скоростью `_gunTrack` = 70°/с — можно обогнать) → 2 ракеты (`Scripts/Combat/Rocket.cs`): перед каждой пунктир оранжево-красных чёрточек до первого препятствия `_aimTime` = 1.1 с, последние `_lockTime` = 0.35 с замирает и мигает, ракета уходит точно по нему; рвётся о стены, укрытия, колонны, стекло, баллоны; убивает героя в радиусе. Между атаками идёт к герою по `NavGrid` (нет пути — напрямую). Взлом «Отказ ног» (`QuickhackEffect.Immobilize`, ассет `Quickhacks/BossLegs`, 8 RAM) — `_immobileTime` = 6 с стоит на месте (искры у ног), но стреляет.
  - **Обрушение**: ракета, попавшая прямо в колонну, рушит её (пули колонны не берут) → вокруг неё на полу мигает зона `_collapseRadius` = 3.2, сыплется пыль, через `_collapseDelay` = 3.5 с падает потолок (обломки, тряска): Босс в зоне теряет 1/4, герой в зоне погибает. Подсказка в задаче: «Ракеты рушат колонны — заманите Босса под обвал».
  - **Газовые баллоны** (`Scripts/World/GasCylinder.cs`): после 4 обрушений мимо Босса (`_missesBeforeGas`) или когда колонн не осталось — сверху падают по 3 баллона (`_dropPoints`, не на голову герою и Боссу); баллон взрывается от пули (и от ракеты), Босс в радиусе 2.4 теряет 1/8, герой погибает, соседние баллоны детонируют; все взорваны, а Босс жив — падает новая волна.

Встретимся на том свете.» → падает замертво, синяя кровь растекается. Помощники по схеме миссий (`V`, `Wall`, `Block`, `Prop`, `Floor`, `Lamp`, `Decor`, `AutoDoorAt`, `SecurityCam`, `BuildBanner`, `BuildWaypoint`, `BuildCity`) — в `Mission01SceneBuilder`; другая миссия с тем же `S` задаёт начало схемы и спрайт стен через `Mission01SceneBuilder.SetLayout`.
- Смерть во время побега перезагружает сцену с чекпоинта (`Scripts/Core/Checkpoint.cs`, статический, сбрасывается из главного меню). Перезагрузка домена при входе в Play Mode в проекте **выключена** — статические поля нужно сбрасывать через `[RuntimeInitializeOnLoadMethod]`.
- Враги корпорации — `Scripts/Enemies/EnemyAI.cs` (охрана и боевые дроны: обзор, реакция, слух на выстрелы, взламываются «Коротким замыканием»: дрон гибнет сразу, а человека (`HackableDevice._isHuman` — охрана, бандиты) не убивает, а оглушает: 2 секунды реального времени (`_malfunctionTime`, замедление TAB не растягивает) судороги с помехами — тряска, красно-голубое раздвоение, разряды, `Scripts/Hacking/Malfunction.cs`; потом он сразу очухивается и идёт к игроку (`EnemyAI.Provoke`); повторно взломать его в это время нельзя, пулей убить можно). Охрана преследует игрока (идёт к месту, где видела/слышала, осматривается и возвращается на пост; если напрямую не пройти — обходит стены по пути из `Scripts/Enemies/NavGrid.cs`: A* по сетке 0.25 юнита над слоями Wall+Glass, строится сама при первом запросе, ничего настраивать на сцене не нужно), дроны с поста не уходят — облетают периметр (`_perimeter`) и сканируют на углах. Сложность — чуть мягче исходной (задаётся в `EnemyPrefab` и вызовах): реакция бандита 0.7 с, охраны 0.6 с, дрона 0.6 с, выстрел раз в 0.5 с (дрон 0.75), разброс 6°, обзор 9.5 юнита, «спиной чувствует» вплотную 2.2 юнита, вражеские пули 23 юн/с (у героя 32) — от них можно увернуться. Убитые оставляют на полу труп поверх лужи крови (`Health._corpseSprite`, лежит навзничь головой назад от того, куда смотрел): `bandit_dead`, `guard_dead`, герой — `hero_dead` (живой спрайт прячется), 89 — `player_dead`; дроны — обломки, как раньше; `Health.SpawnCorpse = false` — тело укладывает кто-то другой (катсцена, удар «Рук гориллы», который отшвыривает именно труп).
- В сборщиках сцен `EditorSceneManager.NewScene` вызывается **до** загрузки ассетов: иначе он выгружает ещё не привязанные ассеты (например, QuickhackData) и в сцену записываются пустые ссылки.
- Физические слои: 6 `Wall`, 7 `Glass` (блокирует пули, но не взлом), 8 `Player`, 9 `Enemy`, 10 `Door` (автодвери: обзор и пули, но не поиск пути). Гравитация 2D выключена.
- Управление: WASD — ходьба, мышь — прицел, ЛКМ — стрельба, зажать Shift — камера уезжает к прицелу (осмотреться), зажать TAB — сканирование (замедление; стрелять нельзя — попытка выстрела срывает скан и текущий взлом, RAM не возвращается), 1–3 — взлом цели под курсором, R — перезарядка (в миссиях), после смерти — мгновенный рестарт, Enter, Space или ЛКМ — пропустить реплику (ЛКМ при стрельбе тоже листает субтитры), Esc — в меню.

## Механики туториала — обязательны в миссиях

Всё, чему учит туториал, должно работать в каждой миссии за главного героя — ничего не урезать и не заменять:

- WASD — ходьба; корпус поворачивается **за мышью** (не по направлению ходьбы);
- перекрестие вместо системного курсора (`Crosshair`, `TutorialSceneBuilder.BuildCrosshair`);
- ЛКМ — стрельба (отдача, тряска камеры);
- камера смещается к курсору, **зажатый Shift** — камера уезжает к прицелу (`CameraFollow`, `_maxLookAhead` = 3, как в туториале);
- зажатый TAB — сканирование с замедлением; стрельба срывает скан и взлом;
- 1–3 — взлом цели под курсором, RAM-слоты с восстановлением и HUD RAM;
- Enter, Space или ЛКМ — пропустить реплику (ЛКМ при стрельбе тоже листает субтитры), Esc — в меню.

В интерлюдиях (дома) у героя нет оружия и взлома, но ходьба, прицел за мышью, перекрестие и Shift — те же, что в миссиях.

## Арсенал: оружие и киберимпланты

- В демо **3 миссии**. Перед каждой — интерлюдия, в ней игрок подходит к арсеналу и выбирает снаряжение на миссию.
- **Оружие (3):** кибер-ПП, автомат, дробовик — можно взять **любое** из трёх перед каждой миссией.
- **Патроны и перезарядка:** патроны бесконечные, но у каждого ствола магазин (`WeaponData._magazineSize`: ПП 16 — самый скорострельный, автомат 25 — медленнее ПП, дробовик 6). Магазин пуст или нажат R — над героем полоска active reload как в Enter the Gungeon (`Scripts/Combat/ActiveReload.cs`): бегунок ходит влево-вправо, ЛКМ в зелёной зоне (`_zoneWidth` = 40% полоски, каждый раз в случайном месте; проход бегунка 0.65 с) — магазин полный (этот клик не стреляет: оружие ждёт, пока ЛКМ отпустят); промах — заминка 0.35 с и новая попытка. R при неполном магазине — та же перезарядка досрочно. Пока идёт перезарядка, оружие не стреляет. Время реальное — замедление TAB не помогает. Счётчик патронов как в Hotline Miami — «16/16rnds» справа внизу (`Scripts/UI/AmmoHud.cs`, часть `BuildHud`; пусто или перезарядка — мигает «RELOAD»; по низу плашки полоска остатка патронов, меньше трети — красная). В туториале у пистолета 89 магазин на 8; перезарядку объясняет `ShootingStep`, досрочную по R — `ReloadStep`. У врагов магазина нет (`_magazineSize` = 0).
- **Киберимпланты (3):** на каждую миссию даётся **один фиксированный** имплант, два других заблокированы (их видно в барабане, но выбрать нельзя).
  - Миссия 1 — **Руки гориллы** (`Scripts/Player/GorillaArms.cs`, на герое в миссии 1 — `Mission01SceneBuilder.AddGorillaArms`; в начале миссии баннер-подсказка):
    - нажать ПКМ (короче 0.18 с) — рывок ~3 юнита туда, куда смотрит корпус, с оранжевыми «призраками»; первый враг перед кулаком (не за стеной) погибает, его тело (копия спрайта) крутясь отлетает ~5 юнитов или до стены и остаётся лежать в синей крови;
    - зажать ПКМ — блок (спрайт `gorilla_guard` перед корпусом, скорость ×0.45, оружие молчит); пули гасит `Health.Guard`; держит 3 попадания (каждое снимает треть шкалы), после третьего блок принудительно снимается и уходит в перезарядку на 7 секунд; подбитый, но не сломанный блок подзаряжается сам (деление за 4 с); `Health.Kill` (сценарные смерти) идёт мимо блока;
    - под спрайтом героя — шкала блока: 3 оранжевых деления, сломан — красная полоса перезарядки; под ней тонкая голубая полоса перезарядки рывка (`_dashCooldown` = 2.5 с): заполняется, вспыхивает, когда рывок готов, тап ПКМ в перезарядке — мигает красным.
  - Миссия 2 — **Руки-лезвия** (ассет `Implants/BladeArms`; `Scripts/Player/BladeArms.cs`, на герое в миссии 2 — `Mission02SceneBuilder.AddBladeArms`; в начале миссии баннер-подсказка):
    - ПКМ — взмах клинком перед собой (туда, куда смотрит корпус), анимация в три фазы: клинок (`blade_arm`, на шарнире у правого предплечья) выбрасывается из руки за `_extendTime` = 0.04 с → проходит дугу ±75° за `_swingTime` = 0.13 с, за ним тянется шлейф (`blade_smear`, передний край на клинке) и веер гаснущих голубых копий клинка (`_ghostInterval`), корпус подаётся вперёд (`_lunge` = 0.1) → вспышка-серп во всю дугу (`blade_slash`), клинок втягивается за `_retractTime` = 0.08 с; взмахи чередуются справа налево и слева направо; оружие во время взмаха молчит; перезарядка `_cooldown` = 0.45 с — тонкая голубая полоса под героем (вспыхивает, когда готово, ПКМ раньше времени — мигает красным);
    - всё в дуге на `_reach` = 1.35 юнита и не за стеной/дверью: белая вспышка по линии разреза и стоп-кадр (`_hitStop` = 0.05 с реального времени, `Time.timeScale` = 0.05, потом возвращается прежнее — замедление TAB не ломается); человек разрублен пополам — его труп режется поперёк в поясе (`_cutAt` = 0.44 ширины от ног) на две половины из кусков спрайта трупа, ноги остаются, верхняя половина отлетает вперёд до стены, синяя кровь и две лужи; дрон взрывается, стекло бьётся;
    - вражеская пуля, оказавшаяся в дуге в первые `_deflectWindow` = 0.26 с взмаха, отбита туда, куда смотрит герой и бьёт уже по врагам (`Bullet.Active` — все летящие пули, `Bullet.Deflect`). Чтобы было видно: расходящееся кольцо (`fx_ring`), сноп бело-голубых искр (`FX_Deflect`), стоп-кадр `_deflectHitStop` = 0.07 с, тряска камеры; сама пуля голубая, в 1.6 раза крупнее, светится (Light2D) и тянет хвост (TrailRenderer).
  - Миссия 3 — имплант пока не определён (заглушка «Засекречено»).
- **Интерфейс выбора** (`Scripts/UI/ArsenalPanel.cs`, `DrumSelector.cs`): полупрозрачный, два вертикальных барабана с эффектом «рыбьего глаза» — слева оружие, справа имплант; по краям экрана панели с описанием выбранного предмета, внизу ENTER — подтвердить. Управление: W/S или колесо — крутить барабан, A/D или наведение мыши — переключить барабан, стрелки ▲▼ кликабельны.
- **Данные** — ScriptableObject: `WeaponData` (`ScriptableObjects/Weapons/`: название, описание, иконка, кулдаун, разброс, дробины, дальность, оценки для полосок) и `ImplantData` (`ScriptableObjects/Implants/`: название, описание, иконка, номер миссии). Создаются сборщиком интерлюдии один раз, дальше тюнятся в инспекторе. Иконки — импортированный арт: `Art/Sprites/Weapons/weapon_smg|rifle|shotgun.png`, `Art/Sprites/Implants/implant_gorilla_arms|blade_arms.png` (фон вырезан, обрезано по содержимому). Сборщик берёт импортированный PNG, если он есть, иначе рисует заглушку кодом (`SpriteFactory.Arsenal.cs`); у импланта миссии 3 пока заглушка `Generated/implant_mission3.png` — новый арт класть как `Art/Sprites/Implants/implant_mission3.png` и т.д. Иконку, поставленную в ассете вручную, сборщик не трогает.
- **Выбор сохраняется** (`Scripts/Core/Loadout.cs`, PlayerPrefs: id ассетов оружия и импланта + номер миссии). Миссия должна стартовать с этим пресетом: найти `WeaponData` по `Loadout.WeaponId` и вызвать `Weapon.Configure(data)`.

## Сюжет (кратко)

Герой (настоящее имя неизвестно, кличка — **Рэй**) — бывший легендарный наёмник. После неудачной миссии он впал в киберпсихоз, его обезвредила и забрала **Корпорация Е** — дочерняя компания одного из двух мировых монополистов «синей крови». Он ничего не помнит и уже 3 года работает на корпорацию цепным псом.

- **Мир:** sci-fi киберпанк с жёстким расслоением общества. «Синяя кровь» — жидкость, проводящая ток и нейросигналы в импланты; жизненно необходима людям с большим количеством имплантов. Формулу знают только две корпорации-монополиста.
- **Настроение:** жутко, драйвово, напряжно, сложно.
- **Номер 89** — ребёнок, за которого игрок проходит **туториал**. В конце обучения его убивают за попытку сбежать.
- **Структура демо (3 миссии):**
  1. **Завязка (миссия 1):** герой начинает интересоваться своим прошлым.
  2. **Развитие (миссия 2):** информацию о себе получить сложно, интерес растёт.
  3. **Кульминация (миссия 3, самая сложная):** герой добывает мощный чип **relic** (отсылка к Relic из Edgerunners) и пытается шантажировать корпорацию.
  4. **Развязка:** корпорация решает его убить. Герой вставляет relic в себя — конструкт чинит простреленный мозг, и герой просыпается на свалке. Конец демо.
- **Концовки (выбор в конце):**
  - *Не отдать relic* — герой выживает, конец демо с завязкой на продолжение.
  - *Отдать relic* — его всё равно убивают, окончательная смерть.
- **Подача сюжета:** перед миссиями — короткие сцены отдыха (герой смотрит в зеркало и думает о прошлом); брифинги — в кабинете босса, который выдаёт досье на цель (как в Katana Zero).

## Уникальные механики

1. **Взлом в духе Cyberpunk 2077** — у игрока есть слоты оперативной памяти (RAM), которые тратятся на взлом и **восстанавливаются со временем**.
2. **Контроль взломанной электроники** — взломанные устройства (камеры, турели, двери и т.п.) можно использовать в своих целях.
3. **Отслеживание взлома NPC** — враги могут засечь попытку взлома или сам взлом и узнать местоположение игрока.

## Игровой цикл

1. Игрок заходит на локацию.
2. Выполняет основную цель миссии.
3. Получает дополнительные очки за: быстрое прохождение, убийство всех врагов, дополнительные задачи.
4. Первые 2 миссии легче третьей. Динамического роста сложности внутри уровня нет.
5. В конце — выбор: отдать relic или нет.

Реиграбельность — 1–2 прохождения: столько нужно, чтобы опробовать все киберимпланты.

## Основные механики и правила

- **Камера:** вид сверху, следует за игроком.
- **Управление:** WASD + мышь (прицел/стрельба), клавиши для взлома и имплантов.
- **Темп:** игрок выбирает сам, но игра поощряет быстрый темп.
- **Поражение:** смерть во время миссии. Как в Hotline Miami, смерть мгновенная: после неё время отматывается к началу уровня, а герой бросает фразу вроде «Это не то» / «Я что-то упускаю».

## Враги и препятствия

| Тип | Поведение | Как избежать | MVP |
|---|---|---|---|
| Враги на уровне | Убивают игрока, как только видят | Убить первым или обойти | Да |
| Ловушки | Убивают игрока | Обойти или обезвредить (в т.ч. взломом) | По возможности |

## UI

- **Меню** в стиле Katana Zero.
- **HUD:** главный индикатор — **доступная память (RAM)** для взлома и манипуляций с техникой. Здоровье не показывается (смерть с одного попадания).
- **Экраны:** старт, игровой, пауза, смерть/рестарт с отмоткой, концовка.

## Арт и звук

- **Стиль:** как в Hotline Miami (top-down, пиксель-арт); палитра и цветокоррекция — неоновый киберпанк и Katana Zero.
- **Свет:** 2D URP Lights и Volume (`Assets/Settings/DefaultVolumeProfile.asset`) для неона и пост-обработки.
- **Музыка:** синтвейв/электроника в духе Tron: Evolution, только треки, которые можно использовать без лицензии (CC0 / royalty-free). Лицензию каждого ассета записывать.

## Состав MVP (приоритет)

Сначала делается то, без чего игру нельзя пройти и показать:

1. Управление и передвижение
2. Главная уникальная механика — взлом с RAM-слотами
3. Минимум один тип врагов (видит → стреляет)
4. Победа / поражение и рестарт (отмотка к старту уровня)
5. Минимальный сюжет (логлайн, мир, персонажи) — брифинг и текстовые вставки

После MVP: катсцены, ловушки, контроль электроники, обнаружение взлома NPC, импланты, система очков, туториал за Номер 89, выбор концовки.

## Правила работы с кодом

- **Объём — джемовский.** Простые, рабочие решения важнее «правильной» архитектуры. Без лишних абстракций, DI-фреймворков и преждевременной оптимизации.
- **Структура `Assets/`** (создавать по мере надобности):
  ```
  Assets/_Project/
    Scripts/     # Player, Enemies, Hacking, UI, Core
    Prefabs/
    Scenes/      # MainMenu, Tutorial, Mission01..03
    Art/         # Sprites, Tiles, Materials
    Audio/
    ScriptableObjects/  # данные оружия, имплантов, взломов, миссий
  ```
- **Баланс и контент — в ScriptableObject** (параметры оружия, стоимость взлома в RAM, скорость восстановления), чтобы можно было тюнить без правок кода.
- Физика — **2D** (`Rigidbody2D`, `Collider2D`, `Physics2D.Raycast` для линии взгляда врагов).
- Именование: `PascalCase` для классов/методов, `_camelCase` для приватных полей, `[SerializeField] private` вместо публичных полей.
- После изменений скриптов проверять консоль Unity на ошибки компиляции (через Unity MCP, если доступен).
- `.meta`-файлы коммитить вместе с ассетами. `Library/`, `Temp/`, `Logs/`, `UserSettings/` в git не попадают.
