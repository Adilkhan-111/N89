## Проект в двух словах

- **Жанр:** top-down shooter, cyberpunk. Hotline Miami + атмосфера Cyberpunk 2077 / Edgerunners.
- **Дедлайн:** 3 дня — **MVP важнее всего остального**.
- **Команда:** Адильхан (основной разработчик), Айбек; арт, звук, сюжет, тесты — оба.

## Техстек

- **Unity 6000.6.6f1**, 2D URP. PC, клавиатура + мышь. Код — **C#**.
- Ввод — новый Input System (`Assets/Settings/InputSystem_Actions.inputactions`). Старый `UnityEngine.Input` не использовать.
- Доступен Unity MCP (`mcp__unity-mcp__*`): логи консоли, скриншоты, команды в редакторе.
- `Assets/Welcome/` — служебная часть шаблона, игровой код туда не класть.
- Шрифты — `Assets/_Project/Art/Fonts/` (Monoton, Audiowide, Permanent Marker). Кириллицы нет — тексты UI на английском.
- **Сцены собираются кодом** (меню **N89 > Build … Scene**, `Scripts/Editor/*SceneBuilder.cs`; все разом — **N89 > Build All Scenes**, `BuildAllScenes.cs`); пересборка затирает ручные правки. Временные спрайты рисуются в `SpriteFactory*.cs` → `Art/Sprites/Generated/` (настоящий арт — PNG с теми же именами).
- Порядок сцен: MainMenu → Tutorial → Interlude01 → Mission01 → Interlude02 → Mission02 → Interlude03 → Mission03 (пока только 1 этаж, конец — в меню).
- В сборщиках `EditorSceneManager.NewScene` вызывается **до** загрузки ассетов, иначе в сцену пишутся пустые ссылки.
- Перезагрузка домена при входе в Play Mode **выключена** — статические поля сбрасывать через `[RuntimeInitializeOnLoadMethod]`. Чекпоинты — `Scripts/Core/Checkpoint.cs` (статический, сброс из меню).
- Физические слои: 6 `Wall`, 7 `Glass` (блокирует пули, но не взлом и не обзор), 8 `Player`, 9 `Enemy`, 10 `Door` (автодвери: обзор и пули, но не поиск пути). Гравитация 2D выключена.
- Управление: WASD, мышь — прицел, ЛКМ — стрельба, Shift — камера к прицелу, TAB — скан с замедлением (выстрел срывает скан и взлом), 1–3 — взлом под курсором, ПКМ — имплант, R — перезарядка / рестарт после смерти, Enter/Space/ЛКМ — пропустить реплику, Esc — пауза (`Scripts/UI/PauseMenu.cs`: продолжить, заново с чекпоинта, главное меню; ввод игры проверяет `PauseMenu.IsPaused`).

## Механики туториала — обязательны в миссиях

Всё, чему учит туториал, должно работать в каждой миссии за главного героя — ничего не урезать и не заменять:

- WASD — ходьба; корпус поворачивается **за мышью**;
- перекрестие вместо курсора (`Crosshair`, `TutorialSceneBuilder.BuildCrosshair`);
- ЛКМ — стрельба (отдача, тряска камеры);
- камера смещается к курсору, **зажатый Shift** — к прицелу (`CameraFollow`, `_maxLookAhead` = 3);
- зажатый TAB — сканирование с замедлением; стрельба срывает скан и взлом;
- 1–3 — взлом цели под курсором, RAM-слоты с восстановлением и HUD RAM (исключение — миссия 3: вместо скана и взлома Сандевистан на TAB со шкалой энергии);
- Enter, Space или ЛКМ — пропустить реплику, Esc — пауза.

В интерлюдиях у героя нет оружия и взлома, но ходьба, прицел за мышью, перекрестие и Shift — те же.

## Арсенал (кратко, подробно — Docs/Arsenal.md)

- 3 миссии, перед каждой — интерлюдия с арсеналом. Оружие (ПП, автомат, дробовик) — любое. Имплант — один фиксированный на миссию: 1 — Руки гориллы, 2 — Руки-лезвия; на 3 — встроенный Сандевистан (TAB, вместо взлома и RAM) + на выбор Руки гориллы или Руки-лезвия.
- Данные — `WeaponData` / `ImplantData` (ScriptableObject). Выбор — `Loadout` (PlayerPrefs); миссия вызывает `Weapon.Configure(data)`.

## Сюжет (кратко)

Герой (кличка **Рэй**, настоящее имя — Брайс) — бывший легендарный наёмник. После киберпсихоза его забрала **Корпорация Е** (дочка одного из двух монополистов «синей крови» — жидкости, проводящей нейросигналы в импланты); он ничего не помнит и 3 года работает на неё цепным псом.

- **Номер 89** — ребёнок, за которого проходят туториал; его убивают за попытку сбежать.
- **Миссии:** 1 — герой начинает интересоваться прошлым; 2 — информацию получить сложно (в конце Босс узнаёт в нём друга); 3 (самая сложная) — добывает чип **relic** и шантажирует корпорацию. Развязка: его убивают, relic чинит мозг, герой просыпается на свалке.
- **Концовки:** не отдать relic — выживает; отдать — окончательная смерть.
- **Настроение:** жутко, драйвово, напряжно. Брифинги — как в Katana Zero.

## Уникальные механики

1. **Взлом** в духе Cyberpunk 2077 — RAM-слоты, восстанавливаются со временем.
2. **Контроль взломанной электроники** (камеры, турели, двери).
3. **Отслеживание взлома NPC** — враги могут засечь взлом и узнать, где игрок.

## Игровой цикл и правила

- Зашёл на локацию → основная цель → бонусы за скорость, всех убитых, доп. задачи. Первые 2 миссии легче третьей.
- Смерть с одного попадания, мгновенная: отмотка к началу/чекпоинту и фраза героя («Это не то»).
- HUD: главный индикатор — RAM; здоровье не показывается.
- **Очки** как в Hotline Miami (`Scripts/UI/ScoreCounter.cs`, часть `BuildHud`): убийство в серии = база (400, Босс 5000) × номер в серии; серия обрывается через 3 с игрового времени без убийства (TAB растягивает) и падает в счёт, смерть сжигает незакрытую серию; счёт переживает чекпоинт. Итоговый экран: набегающий счёт, убийства, макс. серия и ранг S/A/B/C/D (счёт / «пар» = все враги по базе: ≥3 / 2.2 / 1.6 / 1.1).
- Стиль: Hotline Miami (пиксель-арт), палитра — неоновый киберпанк / Katana Zero. Свет — 2D URP Lights + Volume.
- Музыка: синтвейв, только CC0 / royalty-free; лицензию каждого ассета записывать.
- Звуковые эффекты — временные, синтезируются кодом (`Scripts/Core/Sfx.cs`, `Sfx.Play(Sfx.Shot, позиция)`, громкость падает с расстоянием от камеры): выстрел, перезарядка, скан, взлом, попадание, смерть, взрывы, стекло, двери, импланты. Настоящие звуки — заменить синтез в `Sfx.Make`.

## MVP (приоритет)

1. Управление 2. Взлом с RAM 3. Враг «видит → стреляет» 4. Победа / поражение / рестарт 5. Минимальный сюжет.
После MVP: катсцены, ловушки, контроль электроники, обнаружение взлома, импланты, очки, туториал, концовки.

## Правила работы с кодом

- **Объём — джемовский.** Простые рабочие решения, без лишних абстракций.
- Структура: `Assets/_Project/{Scripts,Prefabs,Scenes,Art,Audio,ScriptableObjects}`.
- Баланс и контент — в ScriptableObject.
- Физика — 2D (`Rigidbody2D`, `Physics2D.Raycast`).
- Именование: `PascalCase` для классов/методов, `_camelCase` для приватных полей, `[SerializeField] private`.
- После изменений скриптов проверять консоль Unity на ошибки компиляции.
- `.meta` коммитить вместе с ассетами. `Library/`, `Temp/`, `Logs/`, `UserSettings/` — не в git.
- Изменил механику миссии — обнови соответствующий файл в `Docs/`.
